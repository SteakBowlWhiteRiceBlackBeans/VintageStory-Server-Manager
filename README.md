**# Vintage Story Server Manager**

A lightweight Windows application for managing a **Vintage Story dedicated server**.

It provides a simple graphical interface to:
- Start, stop, and restart the server
- Configurable server data location with field for launch arguments
- View live server console output
- Send server commands
- Manage auto saves, auto backups, and a scheduled restart
- View installed server-side mods **WIP**
- View current player count **WIP**
- View CPU and RAM usage

**How to Install and use:**
- Download the latest release VSSM.zip
- Unzip the folder into a folder to any location you desire
- Launch the server manager .exe
- Hit Start and watch the server turn on

**This still requires you to port forward your own server!**

Optional:
- Open the Settings and enable auto saving / backups (Highly suggest setting a file or folder size limit to the backups to avoid drive space getting maxed)
- You can also change the VS Datapath if you want the server folder to be in a different location.
- Additional startup parameters can be set as well.
- Button to open server config in notepad if you need to make quick changes in there.
